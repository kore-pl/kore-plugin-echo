# kore-plugin-echo — руководство по использованию

Плагин проверки M1 для kore (id `echo`): проверяет полную цепочку хоста `install → hello → invoke → перезапуск после сбоя`. Не предоставляет служебных функций и **не является промышленным плагином** (`depth_level=basic`).

## Установка и совместимость

Устанавливайте опубликованный tar.gz через установщик плагинов kore либо собирайте отдельно (`make build` / `make dist`). Протокол `kore.plugin.v1`, `requires_kore: >=0.1.0 <0.2.0`, `lifecycle=lazy` — инструмент вызывается только при приёмке и не занимает слот резидентного плагина. Он делает четыре вещи: рукопожатие, ответы на вызовы, имитация медленных вызовов/таймаутов/сбоев и корректный выход по `kore.shutdown`. Он не читает `internal/` ядра, не использует сеть и не сохраняет прикладных данных.

## Методы

| Метод | Поведение |
| --- | --- |
| `ping` / `echo.ping` | Возвращает `{"pong":true}` |
| `echo` / `echo.echo` | Возвращает `params` без изменений (не объект → `E_INVALID`) |
| `slow` / `echo.slow` | Спит 1 с и возвращает `{"slept_ms":1000}` |
| `timeout` / `echo.timeout` | Спит 3 с и возвращает `{"slept_ms":3000}`; проверяет таймаут вызова |
| `crash` / `echo.crash` | Немедленно `os.Exit(7)`; проверяет счётчик перезапусков |
| `kore.ping/reload/shutdown` | Обязательные методы протокола; `kore.reload` без конфигурации, пустой `config_digest` |

Ответные кадры повторяют `id` и `req_id` запроса; неизвестный метод → `E_NOTFOUND`. `stdout` выделен только под кадры протокола; логи пишутся в stderr.

## Переменные окружения

| Переменная | Обязательна | Описание |
| --- | --- | --- |
| `KORE_PLUGIN_SOCK` | Да | Путь UDS, созданный хостом |
| `KORE_PLUGIN_ID` | Нет | По умолчанию встроенный `info.json.id` |
| `KORE_PLUGIN_TOKEN` | Нет | В M1 передаётся только с `kore.hello`, пока не проверяется |
| `KORE_LOG_LEVEL` | Нет | debug/info/warn/error, по умолчанию warn |

## Известные ограничения

- В kore M1 нет цикла heartbeat и счётчика перезапусков; код `7` `crash` нужен супервизору.
- `web/` пуст: фронтенда нет.
- Linux — Tier A; остальные платформы не проверены, `rss_kb` возвращает 0.
